# 디지털 트윈·AI 논문 구현 아이디어 분석기

확인한 논문 메타데이터를 키워드·최근성으로 정렬하고 구현 아이디어를 제안합니다.

- 분야: 업무 자동화
- 요구 사항: Python 3.10 이상, 외부 패키지와 API 키 불필요
- 샘플: `papers.json` (합성 데이터 또는 공개 논문 메타데이터)

## 실행

저장소 루트에서 실행합니다.

```bash
python main.py --as-of 2026-10-08 --output PAPER-RADAR.md
```

## 동작과 입출력

기본 샘플 3편의 원문 링크와 매칭 키워드를 표시합니다. 새 메타데이터를 --input으로 공급하면 분석을 다시 수행합니다.

## 설계 판단

AI 출력을 곧바로 장비 동작으로 연결하기 전에 입력 품질, 상태 버전, 모델 적용 범위를 검증해야 한다는 개발자 관점을 적용했습니다. [논문·설계 분석](TRENDS.md)은 공개 원문 자료와 구현자의 해석을 분리합니다.
